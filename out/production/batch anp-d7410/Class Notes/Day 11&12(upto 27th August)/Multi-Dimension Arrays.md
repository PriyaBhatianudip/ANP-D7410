Multi-Dimension Arrays

\----------------------

\- A multi-d array has multiple dimemsions where data is being

stored in rows and columns.

1\. two-d array: to store the values in the form of matrix, rows

and columns, we can use multi-d array.

Syntax:

**To define a 2-d array with size:-**

datatype arrayname\[]\[]=new datatype\[rowsize]\[colsize];

datatype arrayname\[]\[];

arrayname=new datatype\[rowsize]\[colsize];



**To define a 2-d array with values:**

**datatype arrayname\[]\[]={{v1,v2,..},{v1,v2,..},{v1,v2,..},{v1,v2,..}};**

&#x20; **0    1   2**

**0 12, 34, 56**

**1 11, 78, 90**

**2 1,  2,  3**
