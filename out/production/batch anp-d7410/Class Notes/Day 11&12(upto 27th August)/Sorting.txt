1. Bubble Sort :
it checks the values in pairs starting from first value
if first value is greater than second, then it 
swaps the value and then move ahead to the next pair
and repeats the process until it reaches the last value.
In this after the first pass, we get the greatest value
at the last index of array.
and in next passes we continue the same process for rest 
of the values.

2. Insertion sort : 
We can start with the second element, by taking first element as already sorted.
in each iteration we will compare first value with i(index) value, if i value is smaller than the first index, then we swap both of them other wise repeat the same process with the next element until we reach the last index. 
when first pass finishes, we get the smallest element at the first index.
Then we can repeat the same process by taking second value as sorted and continue 
comparing rest of the elements with it one by one.

public int factorial(int n)
{
	if(n==1)
		return 1;
	return n*factorial(n-1);
}
