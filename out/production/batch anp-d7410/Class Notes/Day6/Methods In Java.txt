Methods In Java
---------------
Methods are subroutines which we use to create standalone 
codes, which can be used again and again whenever we need it
They are specially created to perform a specific task.

Difference between Methods and Functions?
Answer:  Methods are defined inside the class. it is the
part of the object. Functions are independent source,
which is not related or bound to a class.

Syntax:
class Demo
{
	access-modifier return-type methodname(parameters)
	{
		code
		return value/object;
	}
}
Access-Modifiers
1. Public    :  the method which is declared as public, will
be accessible from anywhere(same class, other class(inside package, other package, other projects)
2. private: it can only be accessed inside the same class.
3. protected : inside package anyone can access it. But in other packages, only child classes can access it.
4. no-modifier(default) : it can be accessed only inside the same package.


return-type
-----------
The datatype of value returned by a method. if the method is not returning any value, then we use void. return types can be datatypes(int, float, char, String, Array, Collection object, class object etc)


parameters : these are the values, which we will receive as arguments.
		(int id, int age)
--------------------------------------
Method Overloading
-------------------
It let us define methods with same name but with different parameters. 
We can have different number of parameters.
we can have different data type of parameter.
It is part of Polymorphism, where one thing can be used in multiple ways.
