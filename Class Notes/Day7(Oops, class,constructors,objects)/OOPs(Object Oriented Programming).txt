OOPs(Object Oriented Programming)
----------------------------------
A programing language which writes all its code around an object. 
In real world, we have several objects which have features, attributes
etc with them. For example a shop can be treated as an object.
Then the attributes(variables) for this shop will be its name, location,
address, type, owner, area, phone number etc.
features/functions: what functions that shop can perform will be treated
as its features.
Class :  it is a blueprint of an object. it defines what an object can
hold, and what it can perform.
object : it is an instance of a class. it represents what a class can 
do or perform. 
Example:-
	class FirstDemo
	{
		int a;
		static b=100;
		public void calculateNumbers()
		{
		}
	}

classname obname=new classname(parameters);

new keyword : memory allocation. it is used to allocate memory to the object.
classname() :  it calls the constructor of the class. when we write this line with new keyword, constructor returns the size of the class, number of variables.  
Constructor : It is an initializer of a class object. Every java class has a default constructor. Constructor name is similar to its classname. It is a special type of method which is named after the classname, and it does not return any value.
When we define a constructor in a class, then it overrides the default constructor.
Default task of a constructor is to initialize class variables  and allocate memory for objects. But in customized constructor, we can write code, which should run when an object is being created.
