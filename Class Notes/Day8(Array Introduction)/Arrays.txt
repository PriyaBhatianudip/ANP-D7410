Arrays
-------
it is used to store similar type of data in consecutive memory locations.
its index starts from 0.
It is very useful in storing multiple values in the single object.

length: it returns the length of one d array, in multi-d array, it returns 
the length first dimension. 

There are two types of arrays:-
1. Single Dimension array:
There is only one dimension where we can store our data in column-based format.
Syntax:
	datatype arrayname[]= new datatype[size];
	datatype arrayname[]={v1, v2, v3, v4, ......};
	size= arrayname.length

Q why the objects/variables are being initialized inside the constructor? why we are not initializing them when declaring them in class?
Ans.
1. if we define the size or value of an object/variable etc while declaring them in class, then the size of array will be same for every object.
2. The memory of these variables will be defined when the class gets loaded in the memory.
	if later class is not being used, then this space will become waste.
3. if we require different size for array in every object, then we should define it inside the constructor.
