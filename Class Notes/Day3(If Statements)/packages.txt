Use of packages
-   to have project files categorized 
-   to simplify search
-   to limit/control the access to classes, interfaces, methods etc.
-   to avoid naming conflicts
-   to make our code reusable
-   to maintain a large project very easily.

=> to create a package : mention package declaration in the first line of class, interface.

package packagename;

=>to access any variables, method, class or interface of a class from different package, we need to import it into our class.
to access all -> import mainpackage.subpackage.subpackage.*;
to access individual class/interface	
import mainpackage.subpackage.subpackage.classname;

Access Modifiers
| Modifier    | Same Class | Same Package | Subclass | Other Package |
| ----------- | ---------- | ------------ | -------- | ------------- |
| `public`    | ✅          | ✅            | ✅        | ✅             |
| `protected` | ✅          | ✅            | ✅*       | ❌*            |
| default     | ✅          | ✅            | ❌        | ❌             |
| `private`   | ✅          | ❌            | ❌        | ❌             |
