Jagged Array
-------------
An array where each row has different number of columns,
is known as  a jagged array.
it supports real time scenarios. For example
- Every person can have multiple mobile numbers
- Each person can have multiple certificates
- every state has different number of cities.

Syntax
datatype arrayname[][]=new datatype[rows][];

To define the number of columns for each row,
arrayname[rowindex] = new dataype[col-size];
