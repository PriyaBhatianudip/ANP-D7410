Deque in Java :  it is an inbuilt interface of java. It provides many

inbuilt functions of deque. it allows us to add or remove elements from the front and rear of the queue.

Methods of Deque:

\------------------

1\. add(), addFirst(), addLast(), add(collectionobject)

2\. remove(e), removeFirst(), removeLast(), remove(collectionobject)

&#x09;	removeFirstOccureence(e), removeLasOccureence(e)

3\. contains(): it is searching for an element in the queue and returns true or false accordingly.

4\. element():  it is used to get the first element of the queue. it will not remove the element.

5\. offerFirst(), offerLast(), offer(): these functions are used to add an element in the queue.

6\. peek(), peekFirst(), peekLast(): it retrieves but don't remove the element from the queue.

7\. pollFirst(), pollLast(), poll():  it returns and removes the element from the queue.

8\. push():  it is used to add a new element in the queue. it can generate an exception if there are capacity restrictions over the queue. 

9\. size():it returns the total number of elements.
