JAR/WAR
--------
Both are compressed archive file formats just like zip format in windows. 

JAR(Java Archive) : it is a package file format used to aggregate many java .class files, metadata and associated resources into a single file

WAR(Web Application Archive):  it is a special type of JAR used mainly for packaging and distributing web applications.
