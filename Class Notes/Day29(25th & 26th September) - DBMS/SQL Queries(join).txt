CRUD(Create Read Update Delete)
-------------------------------
Delete Query: It is used to delete selected records. It is preferable to use it with some condition.
delete from table name where condition;

=> limit clause:  it is used to get a specific number of rows from the table
starting from the given index. In sql rows have an index starting from 0.

Example(total records : 45)
page 1 :  0-9
page 2 :  10-19
page3  : 20-29
page 4 :  30-39
page 5 : 40-49

limit clause syntax
select collist from tablename limit startindex, totalrecords;

select * from employee limit 0, 10;   for page 1
select * from employee limit 30, 10;  for page 4
Note : limit clause works in MySQL

Like operator:
it is used for pattern wise search operations.
select * from tablename where colname like 'pattern';
we can use some wildcards to create pattern:-
%(percent)    : it is used to represent any number of characters.
_(underscore)  :  it represents only one character.

select * from employee where empname like '%a%';
select * from products where productname like '%shirt%';
-------------------------------------------------------------
in operator
------------
it provides us an option to fetch records according to the given list.
select * from tablename where colname in (value1, value2, .....);

between operator
----------------
it helps us to provide a range of values to fetch records from the table.
select * from tablename where colname between startrange and endrange;

joins/outerjoin/fulljoin :  it joins two tables and returns all the rows when there is a match in either of the tables.
In MySQL, there is no fulljoin or outer join option is available. For doing so, we can use the union operator on left and right join


Left join :  it joins two tables and returns all the records from the left table and only matching records from right table.
