Collection Mapping
-------------------
It is used to map collection objects with the database tables either by creating a separate table which is joined with the main table using foreign key or single table containing all the data in first normal form.

Persistent classes
------------------
List:  is used to store multiple items
Example:-
public class Item
{
	private int itemId;
	private String itemName;
	private String itemtype;
	private List<String> accessories;
}
-> add its mapping in the hbm(hibernate mapping) file
->  create it inside src/main/java
->  Item.hbm.xml
-> for mapping a list with table, we need to use the <list>tag in the hbm file.
	<list name="varname" table="tablename">
		<key column="i\\\_id"></key>
		<index column="typename"></index>
		<element column="varname" type="datatype/objectname"></element>
	</list>

Possible items for <key> column tag
<key
column="columnname"
on-delete="noaction|cascade"
not-null="true|false"
property-ref="propertyName"
update="true|false"
unique="true|false"
/>

Annotation-Based Mapping

Alternative options for xml tags in annotations
 Item.hbm.xml					Annotation equivalent
<class table="stolen\\\_items">			@Table(name = "stolen_items")
<id column="item\\\_id">				@Id and @Column(name = "item_id")
<property name="itemName" column="item\\\_name"/>	@Column(name = "item_name")
<list name="accessories" table="accessories">	@ElementCollection + @CollectionTable
<key column="i\\\_id"/>				@JoinColumn(name = "i_id")
<index column="type"/>				@OrderColumn(name = "type")
<element column="accessory" type="string"/>	@Column(name = "accessory")
